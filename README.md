# Cases

Public record of verification work: what was checked, what proves it, what the result was, and how to
reproduce it.

Most repositories show results. This one shows **the checking**: three payments compared field by field on
a blockchain, a patch against real hardware code, a paper sentence compared with its formal version, and one
case where the answer was "not confirmed".

Each case starts with one plain sentence. If you read only that line, you know what the case is about.

## What is inside, in plain words

**Checking things on a blockchain**
- [201](cases/201-flapjax-payout-verification/): three token payments were claimed; I checked sender, recipient,
  amount and block for each. All twelve fields matched.
- [202](cases/202-mezogig-escrow/): an escrow contract that holds money until work is delivered. Deployed to a
  test network, source verified, tested, and twelve safety rules written down.

**Writing code**
- [101](cases/101-specter-sd-delete/): a hardware wallet's SD card could not delete files. Patch written, tests
  added, pull request open.

**Working for money on platforms**
- [301](cases/301-bounty-submissions/): five paid-task entries that cost nothing to submit.
- [302](cases/302-aibtc-submissions/): three bounty applications, one of which turned out not to be ours; the
  mistake is recorded.

**Applying for funding**
- [401](cases/401-grant-applications/): four applications in one week, with exactly what each funder was told.

**Research**
- [501](cases/501-preprint-doi/): a preprint with a permanent DOI; numbers generated by a script.
- [601](cases/601-statement-scope-review/): a paper's claim compared with its machine-checked version. They differ.
  Verdict: not confirmed.

## How a case is organised

```
cases/NNN-slug/
├── README.md   # one-line summary, claim, evidence, reproduce, verdict, limits
└── evidence.md # optional: links with what each one proves
```

Five short sections, always the same order: **Claim** (what was done), **Evidence** (links and hashes, and what
each proves), **Reproduce** (exact commands), **Verdict** (`confirmed` / `not confirmed` / `could not tell`),
**Limits** (what this case does not establish).

## Rules

- Every claim needs a public link, a transaction hash, or a pinned commit. Otherwise it is an opinion.
- Numbers come from a script and carry a date. A stale count is a wrong count.
- "Not confirmed, here is why" counts the same as "confirmed". Both are published.
