# Case 401 — Four grant applications in one week: what was claimed and what was published

**Date:** 2026-10-25 · **Direction:** grant applications · **Status:** submitted, awaiting decisions

**In one line:** Four grant applications in one week. This records exactly what we told each funder, so the promises can be checked later.

## Claim

Four applications were submitted and their contents are recorded here, so that what we told each funder
can be checked later against what we actually deliver. None of them has been decided; none has been paid.
This case exists because a grant application is a promise, and a promise with no record is a rumour.

## Verdict

**Confirmed** that four applications were submitted on 2026-10-25 with the amounts stated.
**Could not tell** whether any will be funded — no decision has been communicated as of this date.

## Limits

- A submission is not an award. Nothing here is income, and no payment should be assumed until a funder
  says so in writing.
- The Starknet request is $10,000, not the $25,000 the programme advertises, because the round-1 form
  would not accept more. The milestone figures in that form still sum to the larger number; if asked, the
  honest answer is that the milestones scale down proportionally.
- The Foresight application states plainly that we have no personal reference and points at the public
  record instead — at the funder's own suggestion, in writing, on 2026-10-25.
